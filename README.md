# 📚 HTML & CSS — Estudos, Prática e Exploração

Este repositório reúne minha jornada de aprendizado em **HTML5** e **CSS3**, organizado de forma a refletir não apenas exercícios, mas também experimentação, prática consciente e evolução contínua.

---

## 🚀 Proposta

Mais do que armazenar exercícios, este repositório foi estruturado para representar diferentes formas de aprendizado dentro do desenvolvimento front-end:

* Praticar fundamentos
* Resolver desafios
* Explorar ideias e conceitos
* Aplicar conhecimento em projetos mais completos

---

## 🧠 Estrutura do repositório

Cada pasta representa um tipo de abordagem dentro do processo de aprendizado:

```
📁 exercicios/       → prática direta de conceitos fundamentais  
📁 desafios/         → resolução de problemas propostos  
📁 free/             → experimentações livres e testes de ideias  
📁 projeto-final/    → aplicação prática consolidando o aprendizado  
```

---

### 🔹 Exercícios

Focados na compreensão e fixação dos fundamentos de HTML e CSS.

### 🔹 Desafios

Atividades que exigem mais raciocínio e aplicação dos conceitos em conjunto.

### 🔹 Free

Espaço para exploração livre:

* Testes de ideias
* Experimentos com propriedades e layouts
* Implementação de conceitos vistos em artigos, vídeos ou referências externas

### 🔹 Projeto Final

Projeto desenvolvido ao final do ciclo de estudos, com o objetivo de aplicar de forma integrada os conhecimentos adquiridos.

---

## 🎯 Objetivo

Construir uma base sólida em desenvolvimento front-end, priorizando:

* Clareza na estrutura do código
* Organização de arquivos
* Compreensão dos conceitos
* Evolução contínua através da prática

---

## 📈 Evolução

Este repositório não é estático.
Conforme avanço nos estudos, revisito códigos antigos, aplico melhorias e incorporo novas práticas.

---

## 💡 Filosofia de aprendizado

Meu foco não é apenas fazer funcionar, mas entender profundamente o que está sendo construído:

* Buscar o **porquê** das soluções
* Testar diferentes abordagens
* Aprender com erros e experimentações
* Evoluir a organização e legibilidade do código
